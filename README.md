# My First GitHub Project

## What is a GitHub README, and why is it used?
A README is a file that explains what a project is about, how to use it,
and what it contains. It is usually the first thing people see when they
open a repository, so it helps others understand the project quickly.

## What is the difference between Git and GitHub?
Git is a version control tool that tracks changes on your computer, while
GitHub is an online platform that hosts Git repositories.
